گوشی‌های اندرویدی قدیمی و بلااستفاده خود را دور نیندازید! این پروژه به شما اجازه می‌دهد هر گوشی اندرویدی ساده را به یک **دوربین مداربسته و دزدگیر هوشمند با قابلیت تشخیص حرکت** تبدیل کنید که کاملاً محلی (Local)، کم‌مصرف و بدون وابستگی به سرویس‌های ابری خارجی کار می‌کند.

این سیستم با معماری تمیز و ماژولار توسعه یافته و علاوه بر **تلگرام**، از سرویس‌های آزادی چون **ntfy** و **DeltaChat (دلتاچت)** پشتیبانی می‌کند؛ به این معنی که **حتی در زمان قطعی کامل اینترنت بین‌الملل (شبکه ملی)** نیز می‌توانید تصاویر زنده را دریافت کرده و دوربین را از راه دور کنترل کنید.

## ⚡ شروع سریع (در ۶۰ ثانیه)

اگر از قبل اپلیکیشن‌های **Termux** و **Termux:API** را از F-Droid نصب کرده و مجوزهای دوربین و میکروفون را داده‌اید، این دستورات را در ترموکس وارد کنید:

```bash
pkg update -y && pkg install python python-pillow python-numpy termux-api git curl -y
git clone https://github.com/Damoon7/Security-Camera-Termux.git
cd Security-Camera-Termux
python3 SecCam.py --ntfy-topic yek_esm_ramzi_va_tasadofi_entekhab_konid
```

> ⚠️ **نکته امنیتی مهم:** عبارت `yek_esm_ramzi_va_tasadofi_entekhab_konid` را با یک نام دلخواه، رمزی و سخت (مثلاً ترکیبی از حروف و اعداد) جایگزین کنید.
>
> سپس اپلیکیشن رایگان **ntfy** را روی گوشی اصلی خود نصب کنید، همان نام رمزی را سابسکرایب (Subscribe) کنید تا بلافاصله با تکان دادن دست جلوی دوربین، هشدار، عکس و دکمه‌های کنترلی را دریافت نمایید!

## ✨ قابلیت‌های برجسته

* **معماری ماژولار و ساختاریافته:** تفکیک وظایف در فایل‌های مستقل پیکربندی (`config.py`)، پردازش تصویر (`vision.py`)، نظارت باتری و شارژر (`power.py`)، مدیریت پیام‌رسان‌ها (`tg_delta_ntfy_mgr.py`) و اجرای مرکزی (`SecCam.py`).
* **ارسال هشدار سه‌گانه (تلگرام + ntfy + دلتاچت):** قابلیت استفاده هم‌زمان یا جداگانه از تلگرام، پوش نوتیفیکیشن ntfy و پیام‌رسان غیرمتمرکز دلتاچت، با استفاده انحصاری از کتابخانه‌های پیش‌فرض پایتون و بدون نیاز به نصب پکیج‌های سنگین.
* **کارکرد پایدار در زمان اختلال اینترنت:** امکان اتصال به ایمیل‌های هاست ایرانی یا سرورهای بومی در دلتاچت جهت دریافت گزارش‌ها حتی در زمان ملی شدن اینترنت.
* **کالیبراسیون خودکار بدون نیاز به تنظیم دستی:** در ابتدای اجرا نویز سنسور دوربین سنجیده شده و با نرمال‌سازی روشنایی و کنتراست، تغییرات تدریجی نور محیط (مثل طلوع و غروب خورشید یا ابر) باعث آلارم خطا نمی‌شود.
* **فیلتر گلیچ دو فریمی (Glitch Filter):** حذف هشدارهای کاذب حاصل از فوکوس ناگهانی یا خطای سنسور گوشی‌های قدیمی.
* **پنل دکمه‌ای تعاملی:** ایجاد منوی دکمه‌ای در تلگرام و ntfy برای عکس‌برداری فوری (`/snap`)، مشاهده وضعیت و درصد باتری (`/status`)، توقف موقت (`/pause`) و کالیبراسیون مجدد (`/calibrate`).
* **زمان‌بندی ساعات کاری (Schedule):** امکان فعال‌سازی خودکار در ساعات مشخص شب (مثلاً `--schedule 23:00-07:00`) و رفتن به حالت استندبای کم‌مصرف در سایر ساعات.
* **مدیریت مصرف باتری و شارژر:** اعلام وضعیت اتصال یا قطعی شارژر، اعلان افت درصد باتری و بستن خودکار منابع جهت جلوگیری از داغ شدن گوشی.
* **ثبت رویداد هوشمند و فشرده‌سازی:** عکس‌برداری پیوسته تا زمان توقف حرکت، ضبط صدای محیط و امکان تبدیل خودکار فریم‌ها به ویدیوی بهینه‌ی MP4 در صورت نصب `ffmpeg`.

## 📋 پیش‌نیازها

1. **نصب Termux و Termux:API:**
   هر دو برنامه را حتماً از **F-Droid** نصب کنید.
   > ⚠️ **هشدار:** نسخه‌ی موجود در Google Play قدیمی است و توانایی برقراری ارتباط با پکیج API را ندارد.
2. **اعطای دسترسی‌های لازم:**
   در تنظیمات گوشی به مسیر **تنظیمات ➔ برنامه‌ها ➔ Termux:API ➔ مجوزها (Permissions)** بروید و دسترسی‌های زیر را فعال کنید:
   * دوربین (Camera)
   * میکروفون (Microphone)
   * پیامک و تماس (SMS & Phone)
3. **غیرفعال‌سازی بهینه‌سازی باتری (Battery Optimization):**
   مصرف باتری ترموکس را روی حالت **بدون محدودیت (Unrestricted)** بگذارید تا سیستم‌عامل در پس‌زمینه اسکریپت را متوقف نکند.
4. **اتصال مداوم به برق:** پردازش مداوم دوربین مصرف باتری بالایی دارد؛ گوشی را در نقطه‌ای با تهویه مناسب به شارژر متصل نگه دارید.

## 🚀 راهنمای کامل نصب

محیط ترموکس را باز کرده و دستورات زیر را اجرا کنید:

```bash
pkg update && pkg upgrade -y
pkg install python python-pillow python-numpy termux-api git curl -y
```

اگر می‌خواهید فریم‌های تصاویر به صورت ویدیوی کم‌حجم MP4 همراه با صدا تبدیل و ارسال شوند، `ffmpeg` را نیز نصب کنید:

```bash
pkg install ffmpeg -y
```

مخزن پروژه را دریافت کنید:

```bash
git clone https://github.com/Damoon7/Security-Camera-Termux.git
cd Security-Camera-Termux
```

## 💻 تنظیمات کانال‌های ارتباطی (تلگرام / ntfy / دلتاچت)

برای اینکه اطلاعات محرمانه (توکن ربات و رمزها) در تاریخچه ترمینال ذخیره نشوند، آن‌ها را داخل یک فایل محلی امن به نام `~/.seccam_env` قرار دهید:

```bash
nano ~/.seccam_env
```

مقادیر سرویس‌هایی که مایلید فعال شوند را در این فایل بنویسید (فعال‌سازی هر کدام اختیاری است):

```sh
# --- ۱. تنظیمات تلگرام (اختیاری) ---
export TG_BOT_TOKEN="123456:ABC-DEF1234ghIkl-zyx57W2v1u123ew11"
export TG_CHAT_ID="123456789"

# --- ۲. تنظیمات پوش نوتیفیکیشن ntfy (اختیاری) ---
export NTFY_TOPIC="seccam_my_secret_topic_9876"
# export NTFY_CMD_TOPIC="seccam_my_command_topic_9876"
# export NTFY_SERVER="https://ntfy.sh"
# export NTFY_TOKEN="tk_your_optional_token"

# --- ۳. تنظیمات پیام‌رسان دلتاچت / ایمیل SMTP+IMAP (اختیاری) ---
export DC_EMAIL="camera_account@example.com"
export DC_PASSWORD="your_camera_account_password"
export DC_TO="your_personal_account@example.com"
```

فایل را ذخیره کرده (`Ctrl + X` و سپس `Y` و `Enter`)، سطح دسترسی آن را خصوصی کنید و در سیستم بارگذاری نمایید:

```bash
chmod 600 ~/.seccam_env
. ~/.seccam_env
```

### اجرای دوربین:

اجرا با تنظیمات پیش‌فرض (دوربین پشت، حساسیت ۱۰۰٪، نظارت ۲۴ ساعته):

```bash
python3 SecCam.py
```

گوشی را در محل مورد نظر ثابت قرار دهید و چند ثانیه از کادر خارج شوید تا سنسور با نور محیط کالیبره شود.

### متوقف کردن برنامه:

* فشردن کلیدهای `Ctrl + C` در محیط ترموکس
* یا ارسال دستور `/stop confirm` (یا لمس دکمه‌ی **🛑 Stop** در تلگرام/ntfy)

## ⚡ اجرای خودکار پس از روشن شدن گوشی (Termux:Boot)

اگر گوشی خاموش یا ریستارت شد، می‌توانید کاری کنید که سیستم نظارتی به‌طور خودکار بدون دخالت دست بالا بیاید:

1. اپلیکیشن **Termux:Boot** را از F-Droid نصب کنید و یک‌بار آن را از منوی برنامه‌ها باز کنید تا گیرنده پس‌زمینه اندروید فعال شود.
2. اسکریپت راه‌انداز را ایجاد کنید:
   ```bash
   mkdir -p ~/.termux/boot
   nano ~/.termux/boot/start_cam.sh
   ```
3. این خطوط را درون آن قرار دهید:
   ```bash
   #!/data/data/com.termux/files/usr/bin/sh
   termux-wake-lock
   sleep 30
   cd "$HOME/Security-Camera-Termux" || exit 1
   if [ -f "$HOME/.seccam_env" ]; then
       . "$HOME/.seccam_env"
   fi
   python3 SecCam.py > seccam_boot.log 2>&1 &
   ```
4. فایل را اجرایی کنید:
   ```bash
   chmod +x ~/.termux/boot/start_cam.sh
   ```

## 🎮 دستورات کنترل از راه دور

تمامی این دستورات در چت تلگرام، تاپیک ntfy و پیام‌رسان دلتاچت کار می‌کنند:

| دکمه / دستور | کارکرد |
| :--- | :--- |
| **📊 وضعیت** (`/status`) | نمایش وضعیت نظارت، مدت زمان کارکرد، تعداد رویدادها، وضعیت شارژر و درصد باتری |
| **📸 عکس فوری** (`/snap`) | ثبت و ارسال فوری یک عکس زنده از محیط به تمام پیام‌رسان‌ها |
| **⏸️ توقف موقت** (`/pause [دقیقه]`) | مثلاً `/pause 30` برای ۳۰ دقیقه نظارت را معلق می‌کند؛ بدون عدد، توقف نامحدود خواهد بود |
| **▶️ ادامه** (`/resume`) | ادامه‌ی نظارت سریع بدون نیاز به کالیبراسیون سنگین مجدد |
| **🎯 حساسیت** (`/sensitivity [1-500]`) | تغییر درصد حساسیت سنسور (مثلاً `/sensitivity 120`) |
| **🕒 زمان‌بندی** (`/schedule [HH:MM-HH:MM]`) | تعیین ساعات فعال بودن دوربین یا `/schedule off` برای نظارت شبانه‌روزی |
| **🔧 کالیبراسیون** (`/calibrate`) | اجرای کالیبراسیون سنسور در همان لحظه |
| **🛑 خاموش کردن** (`/stop confirm`) | آزادسازی امن منابع سخت‌افزاری و پایان کامل برنامه |

## ⚙️ گزینه‌های مهم خط فرمان (CLI)

| سوئیچ | توضیحات | پیش‌فرض |
| :--- | :--- | :--- |
| `-C`, `--camera` | انتخاب دوربین: `0` (پشت)، `1` (سلفی) | `0` |
| `-v`, `--video` | تبدیل عکس‌های حرکت به ویدیوی MP4 با صدا (`1` یا `0`) | `0` |
| `-st`, `--sensitivity` | درصد حساسیت تشخیص حرکت بین `1` تا `500` | `100` |
| `--schedule` | ساعات نظارت با قالب ۲۴ ساعته (مثال: `22:00-07:00`) | ۲۴ ساعته |
| `-sms`, `--sms` | شماره تلفن جهت ارسال پیامک آلارم | غیرفعال |
| `-c`, `--call` | شماره تلفن جهت برقراری تماس تلفنی آلارم | غیرفعال |
| `--max-events` | تعداد آخرین پوشه‌های رویداد جهت نگهداری (جلوگیری از پر شدن حافظه) | `20` |
| `--interval` | وقفه اضافی بین فریم‌ها بر حسب ثانیه جهت کاهش حرارت پردازنده | `0.0` |
